# 🦀 C-Test Runner для Stepik

Инструмент командной строки на языке Rust для локального тестирования программ на языке C. Идеально подходит для проверки решений задач с образовательных платформ (например, Stepik.org) перед их финальной отправкой.

## ✨ Особенности

- **Безопасность и надежность**: Написан на Rust с строгой обработкой ошибок. Никаких скрытых паник (`unwrap`) или утечек ресурсов.
- **Парсер**: Понимает текстовый формат тестовых данных с маркерами `Test #N input` и `Test #N output`.
- **"Мягкое" сравнение вывода**: Автоматически игнорирует незначительные различия, такие как лишние пробелы в конце строк или разные символы переноса строки (CRLF vs LF).
- **Автоматический поиск тестов**: Если файл с тестами не указан явно, программа автоматически ищет `.txt` файл с тем же именем, что и исходный `.c` файл.
- **Чистота системы**: Использует безопасные временные файлы с гарантированной автоматической очисткой после выполнения.
- **Отчеты**: В случае провала теста наглядно показывает ожидаемый и фактический вывод, а также любые предупреждения из `stderr`.

## 📦 Установка

Для сборки проекта вам потребуется установленный компилятор Rust.
Клонируйте репозиторий:

```bash
git clone https://github.com/your-username/tests_for_stepik.git
cd tests_for_stepik
```

Проверьте работу программы на вашей системе. В комплекте идут два си файла с файлами тестов. При проверке `less_2.c` выдаст сбой `Тест #4: Провален`

```bash
cargo run less_1.c
```

```bash
cargo run less_2.c
```

Сборка оптимизированной версии:

```bash
# Сборка оптимизированной версии
cargo build --release
```

Готовая утилита будет находится по пути `target/release/` c именем `ctrun`

## 🚀 Использование
Потребуется системный компилятор C (например, `gcc` или `clang`) . 
>Настройка пока не реализована. Сейчас в коде "зашит" GCC.

### Базовый запуск (с автопоиском файла тестов)
Если у вас есть файл `task.c` и файл с тестами `task.txt` в одной директории, достаточно указать только C-файл:

```bash
ctrun task.c
```

### Явное указание файлов
Вы можете явно указать путь к файлу с тестами, если он имеет другое имя или находится в другой папке:

```bash
ctrun src/task.c tests/my_custom_tests.txt
```

## 📝 Формат файла с тестами

Программа ожидает текстовый файл со строгой, но читаемой структурой. Пример:

```text
Test #1 input
100 15 30
Test #1 output
100 15 30
75
Test #2 input
50 15 20
Test #2 output
50 15 20
55
```
*Примечание: Парсер устойчив к пустым строкам и корректно обрабатывает переносы строк в стиле Windows (CRLF) и Linux (LF).*
